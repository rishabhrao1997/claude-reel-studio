# Reel assets (starter)

## The rule
If the reel says something exists or happened, show the real thing: the real website, the real repo, the real run. No fake screens. Viewers can tell.

## Steps
1. **Split the script into beats.** For each line, write what must be on screen.
2. **Check every fact on its source.** Open the official page (company post, docs, GitHub repo). Note the link and the exact line. Drop anything you can't verify.
3. **Capture.**
   - Web pages: take screenshots at 2× (Retina) so text stays sharp on a phone.
   - A workflow: actually run it, then screen-record it (QuickTime → File → New Screen Recording). Use dummy data for anything private.
   - Logos: official SVGs from the company's press kit or Wikimedia Commons.
4. **Make long recordings watchable.** Speed them up 4–8× and label them "8×" in the edit.
5. **Put it all in one folder:**

```
<reel>/
  sources.md       links + the line each fact came from
  captures/        screenshots
  recordings/      screen recordings (real-time and sped up)
  logos/
  shot-list.md     beat → file
```

Finish by listing anything only you can film (your phone screen, a real call).
